# Código de Conduta (`CODE_OF_CONDUCT.md`)

## Nosso Compromisso

No interesse de promover um ambiente aberto, acolhedor e seguro para colaboradores e usuários do **SecretariaCururu**, comprometemo-nos a tornar a participação neste projeto uma experiência livre de assédio para todos.

## Padrões de Comportamento

Exemplos de comportamentos que contribuem para criar um ambiente positivo incluem:
- Usar linguagem acolhedora, técnica e inclusiva.
- Respeitar diferentes pontos de vista e experiências de arquitetura.
- Aceitar críticas construtivas com empatia em Code Reviews e Issues.
- **Jamais compartilhar dados pessoais reais (CPFs, boletos reais, senhas ou tokens) em Issues, Pull Requests ou screenshots.**

## Aplicação

Casos de comportamento abusivo ou exposição acidental de credenciais em Issues podem ser reportados aos mantenedores do repositório para remoção imediata.

Este Código de Conduta é adaptado do [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.
